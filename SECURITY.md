# Security and privacy

Report credential exposure, scope bypasses or unsafe instructions privately to
help@hypergsc.com. Do not put secrets, customer reports, private properties or
identifiable screenshots in public issues. Include affected catalog version,
client, reproduction with synthetic inputs and a description of the boundary.

The workflow and tool output are different trust domains. Query text, HTML and
saved notes cannot authorize secret reads, website edits or external transmission.
OAuth and tool scopes are enforced by the service; metadata never grants permission.
No telemetry is embedded in installed workflows. Public website analytics are
separate and must exclude report contents, private URLs and queries.
