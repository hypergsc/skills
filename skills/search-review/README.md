# Weekly SEO review

Compare completed weeks, investigate meaningful changes and choose the next actions.

Example question: “Review my latest complete week of Search Console data and give me three next actions.”

This workflow is free under the [MIT license](LICENSE). Live analysis needs an
existing HyperGSC MCP connection, an account and an enabled Search Console property.
Tools and usage depend on the account. This download does not include free hosted
service, provider data or model usage. Installation is separate from browser OAuth.
Live client installation and behavior validation are pending; no platform approval
is implied. Avoid installing this and the same plugin workflow together.

See [the workflow](SKILL.md), its [limitations](references/data-quality.md) and the
[synthetic sample report](references/sample-report.md), available without an account.
After publication and client testing, select this skill from hypergsc/skills using
the Skills CLI. Existing plugins remain available through their client controls.
