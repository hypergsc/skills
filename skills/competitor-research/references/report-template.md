# Report template

Begin with the property, selected connection (if relevant), exact inclusive periods,
filters, timezone, source and freshness. State retrieved rows, limits and truncation.
Disclose errors and incomplete history. Keep observations separate from hypotheses.

| Competitor page | Market | Provider observation | Existing GSC page | Proposed action | Uncertainty |
| --- | --- | --- | --- | --- | --- |

Use real observations only. Return fewer actions when evidence is insufficient.
For a comparison, use weighted aggregate CTR and percentage-point differences;
zero baseline relative changes are undefined. End with uncertainty and next checks,
without promotional messages. If saving was requested, distinguish the saved record
from a website change. Provider estimates remain distinct from actual GSC data.
