# Launch preparation

Do not launch compatibility claims before the release gates pass. Record three short
consented demos showing the example question, data and decision for content-planning,
ctr-opportunities and search-review. Synthetic demos must label the frame itself.

Candidate post: I made an open-source workflow that turns Search Console data into
a short list of pages worth improving. Here is the workflow and a sample report.
Live data uses HyperGSC, which I build.

Candidate CTR post: This workflow checks snippet opportunities using the available
query evidence and says what remains unknown. Here is the question and sample report.
Live analysis uses HyperGSC, which I build.

Candidate review post: A weekly Search Console review with exact periods, coverage
and three next checks. The workflow runs on demand through HyperGSC, which I build.

Recruit ten qualified testers as a chosen operational goal, not a demand forecast.
Ask each to install one workflow, connect an authorized property, run its question
and describe the first blockage. Record client, install/detection, OAuth, data,
usefulness and follow-up task. Do not require positive reviews. Use only your own
channels and communities whose rules permit it; publication/messages are separate
human-authorized actions. No promotional issues in unrelated repositories.

Check skills.sh indexing after publication. CLI install telemetry is a discovery
signal, not active users or revenue. Do not inflate it with repeated test installs.

Website landing pages and new acquisition tracking are outside the current scope.
For later measurement, consider account_created, search_console_connected,
properties_selected and successful analytic tool events.
A copied command is not an install. get_capabilities/list_properties are discovery,
not first useful analysis. Exclude saves and non-analytic actions from that measure.
Measure by origin cohort/client when the server cannot identify a skill reliably;
landing intent is not proof of the executed workflow. Primary learning measure:
new origin-cohort accounts with property connection and a valid analytic call within
seven days; separately check a call in a later week and interview report usefulness.
Do not include private queries, property URLs, report text or arbitrary MCP tracking
parameters. No telemetry is added inside installed skills.
