# Contributing

Open an issue describing a concrete SEO task or a reproducible failure without
private queries, URLs, reports or credentials. Use example.com and synthetic data.
Contributions may improve a workflow, its contract map or an evaluation fixture.

Read [the authoring guide](docs/contributing-a-skill.md) and [security policy](SECURITY.md).
Keep existing slugs. A new skill must solve a distinct task, have appropriate history
and tools, and include its own evaluation cases; marketing synonyms are not enough.

Run shared-reference synchronization and offline validation. Report exactly which
checks ran. A successful file validator is not a clean client installation or an
analytically correct agent execution. Attach anonymized real-client observations
only with permission to publish them. External contribution CI receives no secrets
or production credentials and has read-only permissions.
